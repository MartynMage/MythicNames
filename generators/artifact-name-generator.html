About Artifact Names

An artifact name should imply a story the party has not heard yet. The formal Object of Concept shape does most of the work, because it implies someone once thought this thing important enough to title.

Naming Patterns

  • The Object of Concept — The Crown of Quiet Years
  • Possessive — the maker or the victim is named
  • Understatement — plain names for terrifying objects work well

Frequently Asked Questions

How should I name a magic artifact?▼
The Object of Concept shape is reliable: a physical noun plus an abstract idea. It implies history without you having to write any yet.
Should the name reveal what it does?▼
Partly. A name that hints without confirming gives players something to investigate, which is usually better than a name that spoils the effect.
How do I make an item feel cursed?▼
Understate it. The Kind Mirror is more unsettling than The Mirror of Screaming Doom, because the gap between name and effect does the work.
Do artifacts need a maker's name?▼
Not always, but a possessive form instantly implies a person, an era and a reason — useful shorthand for setting depth.
