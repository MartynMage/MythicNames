About Minecraft Usernames

Minecraft Java Edition allows 3 to 16 characters, using only letters, numbers and underscores. No spaces, no symbols. Every name this generator produces already fits, so you will not lose one at the sign-up screen.

Bedrock Edition is different: it uses Xbox gamertags, which cap at 12 characters and do allow spaces. If you play Bedrock, stick to the shorter names here.

What Makes a Good One

  • Readable at a glance — it sits above your head in-game
  • Typable — friends will type it to add you
  • Not date-stamped — numbers age a name fast
  • Short enough to survive — long names get truncated in chat

MythicNames is an independent fan tool and is not affiliated with, endorsed by, or associated with Mojang Studios or Microsoft. Names are procedurally generated and free to use.

Frequently Asked Questions

How long can a Minecraft username be?▼
Java Edition allows 3 to 16 characters, using only letters, numbers and underscores. Spaces and symbols are rejected. Bedrock Edition uses Xbox gamertags instead, which cap at 12 characters.
Will these names be available?▼
Availability changes constantly and no generator can promise a free name. Generate a batch, then check the ones you like — shorter names are far more likely to be taken.
Can I use numbers in a Minecraft name?▼
Yes, digits 0 to 9 are allowed anywhere in the name. They are the easiest way to rescue a name you like that is already taken, though a name without them usually ages better.
How often can I change my username?▼
Minecraft allows a username change every 30 days. The old name is held in reserve for a period before anyone else can claim it.
